My first project involving the integration of KiCad with Git and remotely sharing it on GitHub. 
This project has 2-layer and 4-layer version which again was my first attempt with multi-layer boards.
The board uses AtMega328P along with EEPROM, RTC and serial communication interfaces namely SPI and I2C.

Thanks to the author of the book "KiCad like a Pro: Advanced projects and recipes" by Peter Dalmaris for his wonderful approach to teaching PCB design.
